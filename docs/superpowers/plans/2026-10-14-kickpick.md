# KickPick Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сборщик футбольных данных FotMob → Postgres, read-only FastAPI и iOS-приложение на SwiftUI в стиле frosted glass.

**Architecture:** Один Python-пакет `backend/kickpick` с двумя точками входа: `collector` (тик раз в 60 с: полная синхронизация раз в час, лайв, детали, составы) и `api` (FastAPI, только чтение). Формат FotMob знает только `fotmob.py`. Docker Compose поднимает postgres + api + collector. iOS-приложение (`ios/`, XcodeGen) ходит только в наш API; картинки грузит по URL, которые отдаёт API.

**Tech Stack:** Python 3.13, uv, httpx, SQLAlchemy 2.0 + psycopg 3, Alembic, FastAPI, pytest, Postgres 17 (pg_trgm), Docker Compose; Swift 5 mode, SwiftUI iOS 17+, XcodeGen, XCTest.

**Spec:** `docs/superpowers/specs/2026-10-14-kickpick-design.md` + дизайн-система `design.md` (корень репо).

## Global Constraints

- Источник данных — только FotMob (`www.fotmob.com/api/data/...`), заголовок `User-Agent: Mozilla/5.0`, не чаще 1 запроса в 0,5 с, таймаут 20 с.
- Формат FotMob знает только `backend/kickpick/fotmob.py`; при несовпадении формата — исключение до записи в БД.
- Турниры и порядок: premier-league 47, laliga 87, serie-a 55, bundesliga 54, ligue-1 53, eredivisie 57, champions-league 42, europa-league 73, conference-league 10216, euro 50, world-cup 77, nations-league 9806.
- `HISTORY_SEASONS` = 5 по умолчанию; тик 60 с; полная синхронизация раз в 1 ч; деталей ≤ 30 за тик; составов ≤ 10 за тик и не чаще раза в 24 ч.
- Статусы матча: `NS` | `LIVE` | `FT` | `CANC`.
- API только на чтение, без авторизации; держать в локальной сети.
- Картинки: `images.fotmob.com/image_resources/logo/teamlogo/{id}.png`, `.../logo/leaguelogo/dark/{id}.png`, `.../playerimages/{id}.png`; URL собирает API, в БД не хранятся.
- iOS: SwiftUI, iOS 17+, без сторонних зависимостей; строго по `design.md`: тёмно-серый фон, стекло, белый акцент, объёмные кнопки; без эмодзи, без чипов/бейджей у текста; только реальные логотипы; цветных градиентов нет; Barlow Condensed только для цифр.
- Тесты бэкенда пишут только в базу, имя которой оканчивается на `_test`.

## Review Focus

1. **FotMob вернул не тот сезон, что запрошен** (игнорирует `season=`) → backfill не должен снять флаг текущего сезона. Тест: `test_collector.py::test_backfill_rejects_wrong_season` (Task 3).
2. **Сломанный или пустой ответ FotMob** → прежние матчи и таблица остаются. Тест: `test_collector.py::test_broken_payload_keeps_previous_data` (Task 3).
3. **Ввод поиска**: регистр и диакритика (`GARCIA` → `García`), `%`/`_`, одни пробелы, 1 символ. Тесты: `test_api.py::test_search_ignores_accents_and_case`, `test_search_rejects_and_escapes` (Task 4).
4. **Ещё не определённые участники** (`1A`, `Winner SF 1`): расписание показывается, в поиске их нет, в сетке сторона `null` → в iOS «—». Тесты: `test_fotmob.py::test_future_tournament_has_unknown_bracket_sides`, `test_api.py::test_search_rejects_and_escapes`, `DecodingTests.testBracketWithUnknownSide` (Tasks 1, 4, 6).
5. **Время и минута**: минута лайва с невидимыми символами и `HT`; диапазон дат из часового пояса пользователя (`+03:00` в query превратился бы в пробел) → iOS шлёт UTC `Z`, API отвергает время без пояса. Тесты: `test_fotmob.py::test_live_minute_*`, `test_api.py::test_matches_range_validation`, `DecodingTests.testQueryDatesAreUTC` (Tasks 1, 4, 6).

    out = {k: raw.get(k) for k in keys}

`backend/kickpick/fotmob.py`:
```python
"""FotMob: HTTP client and parsers. The only module that knows FotMob's JSON format."""
import re
import time
import unicodedata
from datetime import date, datetime

import httpx

API = "https://www.fotmob.com/api/data"
IMG = "https://images.fotmob.com/image_resources"
POSITIONS = {"coach": "Coach", "keepers": "GK", "defenders": "DF", "midfielders": "MF", "attackers": "FW"}
CARDS = {"Yellow": "yellow", "Red": "red", "YellowRed": "second_yellow"}


def team_logo(team_id: int) -> str:
    return f"{IMG}/logo/teamlogo/{team_id}.png"


def league_logo(league_id: int) -> str:
    return f"{IMG}/logo/leaguelogo/dark/{league_id}.png"


def player_photo(player_id: int) -> str:
    return f"{IMG}/playerimages/{player_id}.png"


def search_name(text: str) -> str:
    # shortcut: NFKD drops accents (García → garcia) but keeps letters like ø/ł/ß; add a translation table if search misses them
    return "".join(c for c in unicodedata.normalize("NFKD", text.lower()) if not unicodedata.combining(c))


class Client:
    def __init__(self, min_interval: float = 0.5, transport: httpx.BaseTransport | None = None):
        self.http = httpx.Client(base_url=API, headers={"User-Agent": "Mozilla/5.0"}, timeout=20, transport=transport)
        self.min_interval = min_interval
        self._last = 0.0

    def _get(self, path: str, **params) -> dict:
        wait = self._last + self.min_interval - time.monotonic()
        if wait > 0:
            time.sleep(wait)
        self._last = time.monotonic()
        r = self.http.get(path, params=params)
        r.raise_for_status()
        return r.json()

    def league(self, league_id: int, season: str | None = None) -> dict:
        return self._get("/leagues", id=league_id, **({"season": season} if season else {}))

    def match(self, match_id: int) -> dict:
        return self._get("/matchDetails", matchId=match_id)

    def team(self, team_id: int) -> dict:
        return self._get("/teams", id=team_id)


def _status(s: dict) -> str:
    if s.get("cancelled"):
        return "CANC"
    if s.get("finished"):
        return "FT"
    return "LIVE" if s.get("started") else "NS"


def _live_minute(s: dict) -> str | None:
    short = (s.get("liveTime") or {}).get("short")
    if _status(s) != "LIVE" or not short:
        return None
    return short.replace("‎", "").replace("’", "'")


def _score(s: dict) -> tuple[int | None, int | None]:
    m = re.fullmatch(r"\s*(\d+)\s*-\s*(\d+)\s*", s.get("scoreStr") or "")
    return (int(m[1]), int(m[2])) if m else (None, None)


def _team(t: dict) -> dict:
    return {"id": int(t["id"]), "name": t["name"], "short_name": t.get("shortName") or t["name"]}


def _tables(raw: dict) -> list[tuple[str, list[dict]]]:
    if not raw.get("table"):
        return []
    data = raw["table"][0]["data"]
    if "tables" in data:  # group stage: "Grp. A" → "A"
        return [(re.sub(r"^Grp\.\s*", "", t["leagueName"]), t["table"]["all"]) for t in data["tables"]]
    return [("", data["table"]["all"])]


def _matchup(m: dict) -> dict:
    def side(team_id, name, tbd):
        return None if tbd or team_id is None else {"id": int(team_id), "name": name}

    return {
        "home": side(m.get("homeTeamId"), m.get("homeTeam"), m.get("tbdTeam1")),
        "away": side(m.get("awayTeamId"), m.get("awayTeam"), m.get("tbdTeam2")),
        "home_score": m.get("homeScore"),
        "away_score": m.get("awayScore"),
        "winner_id": m.get("winner"),
        "match_ids": [int(x["matchId"]) for x in m.get("matches") or []],
    }


def _bracket(playoff: dict | None) -> dict | None:
    if not playoff or not playoff.get("rounds"):
        return None
    return {
        "rounds": [{"stage": r["stage"], "matchups": [_matchup(m) for m in r["matchups"]]} for r in playoff["rounds"]],
        "third_place": _matchup(playoff["bronzeFinal"]) if playoff.get("bronzeFinal") else None,
    }


def parse_league(raw: dict) -> dict:
    teams, matches = {}, []
    for m in raw["fixtures"]["allMatches"]:
        s = m["status"]
        home, away = _team(m["home"]), _team(m["away"])
        teams[home["id"]], teams[away["id"]] = home, away
        home_score, away_score = _score(s)
        matches.append({
            "id": int(m["id"]),
            "round": str(m["round"]),
            "kickoff": datetime.fromisoformat(s["utcTime"]),
            "home_team_id": home["id"],
            "away_team_id": away["id"],
            "home_score": home_score,
            "away_score": away_score,
            "status": _status(s),
            "live_minute": _live_minute(s),
        })
    if not matches:
        raise ValueError("FotMob league payload has no matches")
    standings = []
    for group, rows in _tables(raw):
        for r in rows:
            teams.setdefault(int(r["id"]), _team(r))
            goals_for, goals_against = (int(x) for x in r["scoresStr"].split("-"))
            standings.append({
                "group_name": group,
                "position": r["idx"],
                "team_id": int(r["id"]),
                "played": r["played"],
                "won": r["wins"],
                "drawn": r["draws"],
                "lost": r["losses"],
                "goals_for": goals_for,
                "goals_against": goals_against,
                "points": r["pts"],
            })
    return {
        "season": raw["details"]["selectedSeason"],
        "seasons": raw.get("allAvailableSeasons") or [],
        "teams": list(teams.values()),
        "matches": matches,
        "standings": standings,
        "bracket": _bracket(raw.get("playoff")),
    }


def _top_stats(stats: dict | None) -> list[dict]:
    groups = (((stats or {}).get("Periods") or {}).get("All") or {}).get("stats") or []
    top = next((g for g in groups if g.get("key") == "top_stats"), {})
    return [{"name": i["title"], "home": str(i["stats"][0]), "away": str(i["stats"][1])}
            for i in top.get("stats", []) if len(i.get("stats") or []) == 2 and None not in i["stats"]]


def parse_match(raw: dict) -> dict:
    s = raw["header"]["status"]
    home_score, away_score = _score(s)
    content = raw.get("content") or {}
    events = []
    for e in ((content.get("matchFacts") or {}).get("events") or {}).get("events") or []:
        event = {"minute": e["time"], "added": e.get("overloadTime") or None, "side": "home" if e["isHome"] else "away",
                 "player": e.get("nameStr"), "assist": None, "note": None, "score": None}
        if e["type"] == "Goal" and not e.get("isPenaltyShootoutEvent"):
            events.append(event | {
                "type": "own_goal" if e.get("ownGoal") else "goal",
                "assist": (e.get("assistStr") or "").removeprefix("assist by ") or None,
                "note": e.get("goalDescription"),
                "score": "-".join(map(str, e["newScore"])) if e.get("newScore") else None,
            })
        elif e["type"] == "Card" and e.get("card") in CARDS:
            events.append(event | {"type": CARDS[e["card"]]})
        elif e["type"] == "Substitution" and len(e.get("swap") or []) == 2:
            # swap[0] came on, swap[1] went off (checked against the lineup)
            events.append(event | {"type": "sub", "player": e["swap"][0]["name"], "note": e["swap"][1]["name"]})
    return {
        "status": _status(s),
        "live_minute": _live_minute(s),
        "home_score": home_score,
        "away_score": away_score,
        "details": {"events": events, "stats": _top_stats(content.get("stats"))},
    }


def parse_team(raw: dict) -> dict:
    players, squad = {}, {}
    for group in (raw.get("squad") or {}).get("squad") or []:  # placeholder teams ("Winner SF 1") have no squad
        position = POSITIONS.get(group.get("title"))
        if not position:
            continue
        for p in group["members"]:
            players[p["id"]] = {
                "id": p["id"],
                "name": p["name"],
                "country_code": p.get("ccode"),
                "national_team_id": p.get("nationalTeamId"),
                "position": position,
                "birth_date": date.fromisoformat(p["dateOfBirth"]) if p.get("dateOfBirth") else None,
            }
            squad[p["id"]] = {
                "player_id": p["id"],
                "shirt_number": p.get("shirtNumber"),
                "goals": p.get("goals"),
                "assists": p.get("assists"),
                "yellow_cards": p.get("ycards"),
                "red_cards": p.get("rcards"),
                "rating": p.get("rating"),
            }
    return {"players": list(players.values()), "squad": list(squad.values())}
```

`backend/kickpick/store.py`:
```python
"""Write parsed FotMob data into the DB. Callers own the transaction."""
from datetime import datetime, timezone

from sqlalchemy import delete, update
from sqlalchemy.dialects.postgresql import insert
from sqlalchemy.orm import Session

from kickpick.fotmob import search_name
from kickpick.models import Bracket, Competition, Match, Player, Season, SquadMember, Standing, Team


def _upsert(s: Session, model, rows: list[dict], keys: list[str]) -> None:
    if not rows:
        return
    stmt = insert(model).values(rows)
    changes = {c: stmt.excluded[c] for c in rows[0] if c not in keys}
    s.execute(stmt.on_conflict_do_update(index_elements=keys, set_=changes) if changes else stmt.on_conflict_do_nothing())


def save_competitions(s: Session, competitions: list[tuple]) -> None:
    _upsert(s, Competition, [{"id": i, "slug": slug, "name": name, "kind": kind, "search_name": search_name(name)}
                             for i, slug, name, kind in competitions], ["id"])


def save_league(s: Session, competition_id: int, parsed: dict, is_current: bool) -> int:
    if is_current:
        s.execute(update(Season).where(Season.competition_id == competition_id).values(is_current=False))
    season_id = s.execute(
        insert(Season).values(competition_id=competition_id, name=parsed["season"], is_current=is_current)
        .on_conflict_do_update(index_elements=["competition_id", "name"], set_={"is_current": is_current})
        .returning(Season.id)
    ).scalar_one()
    _upsert(s, Team, [t | {"search_name": search_name(t["name"])} for t in parsed["teams"]], ["id"])
    _upsert(s, Match, [m | {"season_id": season_id} for m in parsed["matches"]], ["id"])
    s.execute(delete(Standing).where(Standing.season_id == season_id))
    _upsert(s, Standing, [r | {"season_id": season_id} for r in parsed["standings"]],
            ["season_id", "group_name", "team_id"])
    if parsed["bracket"]:
        _upsert(s, Bracket, [{"season_id": season_id, "data": parsed["bracket"]}], ["season_id"])
    return season_id


def save_match(s: Session, match_id: int, parsed: dict) -> None:
    s.execute(update(Match).where(Match.id == match_id).values(
        status=parsed["status"],
        live_minute=parsed["live_minute"],
        home_score=parsed["home_score"],
        away_score=parsed["away_score"],
        details=parsed["details"],
        details_final=parsed["status"] in ("FT", "CANC"),
    ))


def save_squad(s: Session, team_id: int, parsed: dict) -> None:
    _upsert(s, Player, [p | {"search_name": search_name(p["name"])} for p in parsed["players"]], ["id"])
    s.execute(delete(SquadMember).where(SquadMember.team_id == team_id))
    _upsert(s, SquadMember, [m | {"team_id": team_id} for m in parsed["squad"]], ["team_id", "player_id"])
    touch_squad(s, team_id)


def touch_squad(s: Session, team_id: int) -> None:
    s.execute(update(Team).where(Team.id == team_id).values(squad_updated_at=datetime.now(timezone.utc)))
```

```python
"""Keeps the DB in sync with FotMob.

    python -m kickpick.collector            # loop: one tick every 60 s
    python -m kickpick.collector backfill   # one-off: past seasons
"""
import logging
import sys
import time
from datetime import datetime, timedelta, timezone

from sqlalchemy import and_, or_, select

from kickpick import fotmob, store
from kickpick.config import COMPETITIONS, HISTORY_SEASONS
from kickpick.db import SessionLocal
from kickpick.models import Match, Season, Team

log = logging.getLogger("kickpick.collector")
FULL_SYNC_EVERY = timedelta(hours=1)
DETAILS_PER_TICK = 30
SQUADS_PER_TICK = 10


def sync_competition(client, competition_id: int, season: str | None = None) -> dict:
    parsed = fotmob.parse_league(client.league(competition_id, season))
    if season and parsed["season"] != season:
        raise ValueError(f"asked FotMob for {season}, got {parsed['season']}")
    with SessionLocal.begin() as s:
        store.save_league(s, competition_id, parsed, is_current=season is None)
    return parsed


def sync_match(client, match_id: int) -> None:
    parsed = fotmob.parse_match(client.match(match_id))
    with SessionLocal.begin() as s:
        store.save_match(s, match_id, parsed)


def sync_team(client, team_id: int) -> None:
    try:
        parsed = fotmob.parse_team(client.team(team_id))
    except Exception:
        with SessionLocal.begin() as s:
            store.touch_squad(s, team_id)  # don't retry a broken team every minute
        raise
    with SessionLocal.begin() as s:
        store.save_squad(s, team_id, parsed)


def live_competitions(s, now: datetime) -> set[int]:
    soon = and_(Match.status == "NS", Match.kickoff.between(now - timedelta(hours=3), now + timedelta(minutes=15)))
    q = select(Season.competition_id).join(Match, Match.season_id == Season.id).where(or_(Match.status == "LIVE", soon))
    return set(s.scalars(q.distinct()))


def matches_needing_details(s, limit: int) -> list[int]:
    live = list(s.scalars(select(Match.id).where(Match.status == "LIVE")))
    rest = s.scalars(select(Match.id).where(Match.status == "FT", Match.details_final.is_(False))
                     .order_by(Match.kickoff.desc()).limit(max(limit - len(live), 0)))
    return live + list(rest)


def teams_needing_squads(s, now: datetime, limit: int) -> list[int]:
    current = (select(Match.home_team_id, Match.away_team_id)
               .join(Season, Match.season_id == Season.id).where(Season.is_current).subquery())
    q = (select(Team.id)
         .where(or_(Team.id.in_(select(current.c.home_team_id)), Team.id.in_(select(current.c.away_team_id))))
         .where(or_(Team.squad_updated_at.is_(None), Team.squad_updated_at < now - timedelta(hours=24)))
         .order_by(Team.squad_updated_at.asc().nulls_first())
         .limit(limit))
    return list(s.scalars(q))


def _try(what: str, fn, *args) -> None:
    try:
        fn(*args)
    except Exception:
        log.exception("%s failed", what)


def tick(client, state: dict, now: datetime | None = None) -> None:
    now = now or datetime.now(timezone.utc)
    synced = set()
    if state.get("full_sync_at") is None or now - state["full_sync_at"] >= FULL_SYNC_EVERY:
        for competition_id, slug, *_ in COMPETITIONS:
            _try(f"league {slug}", sync_competition, client, competition_id)
            synced.add(competition_id)
        state["full_sync_at"] = now
    with SessionLocal() as s:
        live = live_competitions(s, now) - synced
    for competition_id in live:
        _try(f"live league {competition_id}", sync_competition, client, competition_id)
    with SessionLocal() as s:
        match_ids = matches_needing_details(s, DETAILS_PER_TICK)
        team_ids = teams_needing_squads(s, now, SQUADS_PER_TICK)
    for match_id in match_ids:
        _try(f"match {match_id}", sync_match, client, match_id)
    for team_id in team_ids:
        _try(f"team {team_id}", sync_team, client, team_id)


def backfill(client, seasons: int = HISTORY_SEASONS) -> None:
    for competition_id, slug, *_ in COMPETITIONS:
        try:
            available = sync_competition(client, competition_id)["seasons"]
        except Exception:
            log.exception("league %s failed", slug)
            continue
        for season in available[1:seasons]:
            _try(f"{slug} {season}", sync_competition, client, competition_id, season)


def main(argv: list[str]) -> None:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s %(message)s")
    client = fotmob.Client()
    with SessionLocal.begin() as s:
        store.save_competitions(s, COMPETITIONS)
    if argv == ["backfill"]:
        backfill(client)
        return
    state: dict = {}
    while True:
        started = time.monotonic()
        try:
            tick(client, state)
        except Exception:
            log.exception("tick failed")
        time.sleep(max(0.0, 60 - (time.monotonic() - started)))


if __name__ == "__main__":
    main(sys.argv[1:])
```

"""Read-only HTTP API for the iOS app."""
from datetime import datetime, timedelta, timezone

from fastapi import Depends, FastAPI, HTTPException, Query
from sqlalchemy import func, or_, select
from sqlalchemy.orm import Session, aliased

from kickpick.config import COMPETITIONS
from kickpick.db import SessionLocal
from kickpick.fotmob import league_logo, player_photo, search_name, team_logo
from kickpick.models import Bracket, Competition, Match, Player, Season, SquadMember, Standing, Team

app = FastAPI(title="KickPick")
ORDER = {competition_id: i for i, (competition_id, *_) in enumerate(COMPETITIONS)}
POSITIONS = ["Coach", "GK", "DF", "MF", "FW"]
Home, Away = aliased(Team), aliased(Team)
MATCHES = (select(Match, Season, Competition, Home, Away)
           .join(Season, Match.season_id == Season.id)
           .join(Competition, Season.competition_id == Competition.id)
           .join(Home, Match.home_team_id == Home.id)
           .join(Away, Match.away_team_id == Away.id))


def db():
    with SessionLocal() as s:
        yield s


def team_json(t: Team) -> dict:
    return {"id": t.id, "name": t.name, "short_name": t.short_name, "logo_url": team_logo(t.id)}


def competition_json(c: Competition, current_season: str | None) -> dict:
    return {"slug": c.slug, "name": c.name, "kind": c.kind, "current_season": current_season, "logo_url": league_logo(c.id)}


def match_json(row) -> dict:
    m, season, competition, home, away = row
    return {
        "id": m.id,
        "competition": {"slug": competition.slug, "name": competition.name, "logo_url": league_logo(competition.id)},
        "season": season.name,
        "round": m.round,
        "kickoff": m.kickoff,
        "status": m.status,
        "minute": m.live_minute,
        "home": team_json(home),
        "away": team_json(away),
        "home_score": m.home_score,
        "away_score": m.away_score,
    }


def stats_json(m: SquadMember) -> dict:
    return {"goals": m.goals, "assists": m.assists, "yellow_cards": m.yellow_cards,
            "red_cards": m.red_cards, "rating": m.rating}


def bracket_json(data: dict) -> dict:
    def side(t):
        return t and t | {"logo_url": team_logo(t["id"])}

    def pair(m):
        return m and m | {"home": side(m["home"]), "away": side(m["away"])}

    return {"rounds": [r | {"matchups": [pair(m) for m in r["matchups"]]} for r in data["rounds"]],
            "third_place": pair(data["third_place"])}


def find_season(s: Session, slug: str, season: str | None) -> Season:
    q = select(Season).join(Competition, Season.competition_id == Competition.id).where(Competition.slug == slug)
    found = s.scalar(q.where(Season.name == season) if season else q.where(Season.is_current))
    if not found:
        raise HTTPException(404, "season not found")
    return found


def all_competitions(s: Session) -> list[dict]:
    rows = s.execute(select(Competition, Season.name)
                     .outerjoin(Season, (Season.competition_id == Competition.id) & Season.is_current)).all()
    rows.sort(key=lambda r: ORDER.get(r[0].id, len(ORDER)))
    return [competition_json(c, season) for c, season in rows]


@app.get("/health")
def health():
    return {"ok": True}


@app.get("/competitions")
def competitions(s: Session = Depends(db)):
    return all_competitions(s)


@app.get("/competitions/{slug}/seasons")
def seasons(slug: str, s: Session = Depends(db)):
    names = s.scalars(select(Season.name).join(Competition, Season.competition_id == Competition.id)
                      .where(Competition.slug == slug).order_by(Season.name.desc())).all()
    if not names:
        raise HTTPException(404, "competition not found")
    return names


@app.get("/competitions/{slug}/standings")
def standings(slug: str, season: str | None = None, s: Session = Depends(db)):
    found = find_season(s, slug, season)
    rows = s.execute(select(Standing, Team).join(Team, Standing.team_id == Team.id)
                     .where(Standing.season_id == found.id).order_by(Standing.group_name, Standing.position))
    groups: dict[str, list] = {}
    for st, team in rows:
        groups.setdefault(st.group_name, []).append({
            "position": st.position, "team": team_json(team), "played": st.played, "won": st.won,
            "drawn": st.drawn, "lost": st.lost, "goals_for": st.goals_for, "goals_against": st.goals_against,
            "points": st.points,
        })
    return [{"group": g, "rows": r} for g, r in groups.items()]


@app.get("/competitions/{slug}/matches")
def competition_matches(slug: str, season: str | None = None, round: str | None = None, s: Session = Depends(db)):
    q = MATCHES.where(Match.season_id == find_season(s, slug, season).id).order_by(Match.kickoff)
    if round:
        q = q.where(Match.round == round)
    return [match_json(r) for r in s.execute(q)]


@app.get("/competitions/{slug}/bracket")
def bracket(slug: str, season: str | None = None, s: Session = Depends(db)):

    if not found:
        raise HTTPException(404, "no bracket")
    return bracket_json(found.data)


@app.get("/matches")
def matches(start: datetime = Query(alias="from"), end: datetime = Query(alias="to"), s: Session = Depends(db)):
    if start.tzinfo is None or end.tzinfo is None:
        raise HTTPException(422, "from/to need a timezone, e.g. 2026-10-14T00:00:00Z")
    if not timedelta(0) < end - start <= timedelta(days=7):
        raise HTTPException(422, "to must be after from, at most 7 days later")
    q = MATCHES.where(Match.kickoff >= start, Match.kickoff < end).order_by(Match.kickoff)
    return [match_json(r) for r in s.execute(q)]


@app.get("/matches/live")

def match(match_id: int, s: Session = Depends(db)):
    row = s.execute(MATCHES.where(Match.id == match_id)).first()
    if not row:
        raise HTTPException(404, "match not found")
    return match_json(row) | {"details": row[0].details}


@app.get("/teams/{team_id}")
def team(team_id: int, s: Session = Depends(db)):
    found = s.get(Team, team_id)
    if not found:
        raise HTTPException(404, "team not found")
    squad = s.execute(select(SquadMember, Player).join(Player, SquadMember.player_id == Player.id)
                      .where(SquadMember.team_id == team_id)).all()
    squad.sort(key=lambda r: (POSITIONS.index(r[1].position) if r[1].position in POSITIONS else len(POSITIONS),
                              r[0].shirt_number or 999))
    plays = MATCHES.where(or_(Match.home_team_id == team_id, Match.away_team_id == team_id))
    last = s.execute(plays.where(Match.status == "FT").order_by(Match.kickoff.desc()).limit(10))
    upcoming = s.execute(plays.where(Match.status.in_(("NS", "LIVE")),
                                     Match.kickoff > datetime.now(timezone.utc) - timedelta(hours=3))
                         .order_by(Match.kickoff).limit(5))
    return team_json(found) | {
        "squad": [{"player": {"id": p.id, "name": p.name, "photo_url": player_photo(p.id)},
                   "shirt_number": m.shirt_number, "position": p.position, "stats": stats_json(m)} for m, p in squad],
        "last": [match_json(r) for r in last],
        "next": [match_json(r) for r in upcoming],
    }


@app.get("/players/{player_id}")
def player(player_id: int, s: Session = Depends(db)):
    found = s.get(Player, player_id)
    if not found:
        raise HTTPException(404, "player not found")
    rows = s.execute(select(SquadMember, Team).join(Team, SquadMember.team_id == Team.id)
                     .where(SquadMember.player_id == player_id)).all()
    rows.sort(key=lambda r: r[1].id == found.national_team_id)  # club first, national team last
    return {
        "id": found.id, "name": found.name, "photo_url": player_photo(found.id), "country_code": found.country_code,
        "position": found.position, "birth_date": found.birth_date,
        "teams": [{"team": team_json(t), "shirt_number": m.shirt_number, "stats": stats_json(m)} for m, t in rows],
    }


@app.get("/search")
def search(q: str = Query(min_length=2, max_length=50), s: Session = Depends(db)):
    term = search_name(q.strip())
    if len(term) < 2:
        raise HTTPException(422, "query must have at least 2 characters")
    pattern = "%" + term.replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_") + "%"

    def find(model, *where):
        return s.scalars(select(model).where(model.search_name.like(pattern, escape="\\"), *where)
                         .order_by(func.similarity(model.search_name, term).desc()).limit(10)).all()

    competition_slugs = {c.slug for c in find(Competition)}
    players = find(Player)
    clubs = dict(s.execute(
        select(SquadMember.player_id, Team.name)
        .join(Team, SquadMember.team_id == Team.id)
        .join(Player, SquadMember.player_id == Player.id)
        .where(SquadMember.player_id.in_([p.id for p in players]),
               or_(Player.national_team_id.is_(None), SquadMember.team_id != Player.national_team_id))
    ).all())
    return {
        "competitions": [c for c in all_competitions(s) if c["slug"] in competition_slugs],
        # only teams with a squad: hides FotMob placeholders like "Winner SF 1"
        "teams": [team_json(t) for t in find(Team, Team.id.in_(select(SquadMember.team_id)))],
        "players": [{"id": p.id, "name": p.name, "photo_url": player_photo(p.id), "team_name": clubs.get(p.id)}
                    for p in players],
    }

import XCTest
@testable import KickPick

final class DecodingTests: XCTestCase {
    private func decode<T: Decodable>(_ type: T.Type, _ json: String) throws -> T {
        try JSONDecoder.api.decode(T.self, from: Data(json.utf8))
    }

    private let matchJSON = """
    {"id": 1, "competition": {"slug": "premier-league", "name": "Premier League",
      "logo_url": "https://images.fotmob.com/image_resources/logo/leaguelogo/dark/47.png"},
     "season": "2026/2027", "round": "6", "kickoff": "2026-10-12T19:00:00Z", "status": "LIVE", "minute": "45+2'",
     "home": {"id": 8669, "name": "Coventry City", "short_name": "Coventry",
              "logo_url": "https://images.fotmob.com/image_resources/logo/teamlogo/8669.png"},
     "away": {"id": 10261, "name": "Newcastle United", "short_name": "Newcastle", "logo_url": null},
     "home_score": 4, "away_score": 1
    """

    func testMatchDecodes() throws {
        let match = try decode(Match.self, matchJSON + "}")
        XCTAssertEqual(match.status, .live)
        XCTAssertEqual(match.minute, "45+2'")
        XCTAssertEqual(match.home.logoUrl?.lastPathComponent, "8669.png")
        XCTAssertEqual(match.kickoff, ISO8601DateFormatter().date(from: "2026-10-12T19:00:00Z"))
        XCTAssertEqual(match.weight(home: true), .even)  // still live: no winner yet
    }

    func testMatchPageWithDetailsDecodes() throws {
        let page = try decode(MatchPage.self, matchJSON + """
        , "details": {"events": [{"minute": 90, "added": 5, "type": "goal", "side": "away", "player": "A",
          "assist": "B", "note": null, "score": "4-2"}], "stats": [{"name": "Ball possession", "home": "73", "away": "27"}]}}
        """)
        XCTAssertEqual(page.match.id, 1)
        XCTAssertEqual(page.details?.events.first?.minuteText, "90+5'")
        XCTAssertEqual(page.details?.stats.first?.homeValue, 73)
    }

    func testFractionalDatesDecode() throws {
        let match = try decode(Match.self, matchJSON.replacingOccurrences(of: "19:00:00Z", with: "19:00:00.000Z") + "}")
        XCTAssertEqual(match.kickoff, ISO8601DateFormatter().date(from: "2026-10-12T19:00:00Z"))
    }

    func testBracketWithUnknownSide() throws {
        let bracket = try decode(Bracket.self, """
        {"rounds": [{"stage": "1/8", "matchups": [{"home": null,
          "away": {"id": 9847, "name": "PSG", "logo_url": "https://images.fotmob.com/image_resources/logo/teamlogo/9847.png"},
          "home_score": null, "away_score": null, "winner_id": null, "match_ids": []}]}], "third_place": null}
        """)
        XCTAssertNil(bracket.rounds[0].matchups[0].home)
        XCTAssertEqual(bracket.rounds[0].matchups[0].away?.name, "PSG")
    }

    func testSearchDecodes() throws {
        let results = try decode(SearchResults.self, """
        {"competitions": [{"slug": "champions-league", "name": "Champions League", "kind": "cup",
          "current_season": "2026/2027", "logo_url": null}],
         "teams": [{"id": 8634, "name": "Barcelona", "short_name": "Barcelona", "logo_url": null}],
         "players": [{"id": 1, "name": "Joan García", "photo_url": null, "team_name": "Barcelona"}]}

        XCTAssertEqual(results.players[0].teamName, "Barcelona")

    }

import Foundation

struct TeamRef: Codable, Hashable, Identifiable {

    let shortName: String?

struct CompetitionRef: Codable, Hashable {

    var id: String { slug }
    let slug: String
    let name: String
    let kind: String
    let currentSeason: String?
    let logoUrl: URL?
}

enum MatchStatus: String, Codable {
    case notStarted = "NS", live = "LIVE", finished = "FT", cancelled = "CANC"
}

struct Match: Codable, Hashable, Identifiable {
    let id: Int
    let competition: CompetitionRef
    let season: String
    let round: String
    let kickoff: Date
    let status: MatchStatus
    let minute: String?
    let home: TeamRef
    let away: TeamRef
    let homeScore: Int?
    let awayScore: Int?
}

struct MatchEvent: Codable, Hashable {
    let minute: Int
    let added: Int?
    let type: String
    let side: String
    let player: String?
    let assist: String?
    let note: String?
    let score: String?

    var minuteText: String { added.map { "\(minute)+\($0)'" } ?? "\(minute)'" }
}

struct MatchStat: Codable, Hashable {
    let name: String
    let home: String
    let away: String

    var homeValue: Double { Self.number(home) }
    var awayValue: Double { Self.number(away) }

    /// "185 (70%)" → 185, "1.47" → 1.47
    static func number(_ text: String) -> Double {
        Double(text.prefix { $0.isNumber || $0 == "." }) ?? 0
    }

import Foundation

enum APIError: Error {
    case status(Int)
}

struct APIClient {
    static let shared = APIClient(
        base: URL(string: Bundle.main.object(forInfoDictionaryKey: "APIBaseURL") as? String ?? "")
            ?? URL(string: "http://localhost:8000")!)

    let base: URL

    /// Always UTC with "Z": a "+03:00" offset would turn into a space in the query string.
    static func isoUTC(_ date: Date) -> String {
        ISO8601DateFormatter().string(from: date)
    }

    func get<T: Decodable>(_ path: String, query: [String: String] = [:]) async throws -> T {
        var components = URLComponents(url: base.appending(path: path), resolvingAgainstBaseURL: false)!
        if !query.isEmpty {
            components.queryItems = query.sorted { $0.key < $1.key }.map { URLQueryItem(name: $0.key, value: $0.value) }
        }
        let (data, response) = try await URLSession.shared.data(from: components.url!)
        let code = (response as? HTTPURLResponse)?.statusCode ?? 0
        guard code == 200 else { throw APIError.status(code) }
        return try JSONDecoder.api.decode(T.self, from: data)
    }

    func competitions() async throws -> [Competition] { try await get("competitions") }
    func seasons(_ slug: String) async throws -> [String] { try await get("competitions/\(slug)/seasons") }

    func standings(_ slug: String, season: String?) async throws -> [StandingGroup] {
        try await get("competitions/\(slug)/standings", query: seasonQuery(season))
    }

    func matches(_ slug: String, season: String?) async throws -> [Match] {
        try await get("competitions/\(slug)/matches", query: seasonQuery(season))
    }

    func bracket(_ slug: String, season: String?) async throws -> Bracket? {
        do {
            return try await get("competitions/\(slug)/bracket", query: seasonQuery(season))
        } catch APIError.status(404) {
            return nil
        }
    }

    func matches(from: Date, to: Date) async throws -> [Match] {
        try await get("matches", query: ["from": Self.isoUTC(from), "to": Self.isoUTC(to)])
    }

    func match(_ id: Int) async throws -> MatchPage { try await get("matches/\(id)") }
    func team(_ id: Int) async throws -> TeamPage { try await get("teams/\(id)") }
    func player(_ id: Int) async throws -> PlayerPage { try await get("players/\(id)") }
    func search(_ text: String) async throws -> SearchResults { try await get("search", query: ["q": text]) }

    private func seasonQuery(_ season: String?) -> [String: String] {
        season.map { ["season": $0] } ?? [:]
    }
}

import SwiftUI

/// Loads a value and shows it; offers a retry on failure; while `live(value)` is true, reloads every 30 s.
struct Loader<Value, Content: View>: View {
    var id: AnyHashable = 0
    var placeholder: Value? = nil
    var live: (Value) -> Bool = { _ in false }
    let load: () async throws -> Value
    @ViewBuilder let content: (Value) -> Content

    @State private var value: Value?
    @State private var loadedID: AnyHashable?
    @State private var failed = false
    @State private var attempt = 0

    var body: some View {
        Group {
            if let value {
                content(value)
            } else if failed {
                ErrorState { failed = false; attempt += 1 }
            } else if let placeholder {
                content(placeholder).redacted(reason: .placeholder).disabled(true)
            } else {
                ProgressView().frame(maxWidth: .infinity, minHeight: 240)
            }
        }
        .task(id: [id, AnyHashable(attempt)]) {
            if loadedID != id { value = nil }
            await reload()
            loadedID = id
            while let current = value, live(current), !Task.isCancelled {
                try? await Task.sleep(for: .seconds(30))
                await reload()
            }
        }
    }

    private func reload() async {
        do {
            value = try await load()
            failed = false
        } catch is CancellationError {
        } catch let error as URLError where error.code == .cancelled {
        } catch {
            if value == nil { failed = true }
        }
    }
}

struct Grouped<Key: Hashable, Item>: Identifiable {
    let key: Key
    let items: [Item]
    var id: Key { key }

extension Array {
    /// Groups in first-appearance order.
    func grouped<Key: Hashable>(by key: (Element) -> Key) -> [Grouped<Key, Element>] {
        var order: [Key] = []
        var groups: [Key: [Element]] = [:]
        for element in self {
            let k = key(element)
            if groups[k] == nil { order.append(k) }
            groups[k, default: []].append(element)
        }
        return order.map { Grouped(key: $0, items: groups[$0]!) }
    }
}

struct CompetitionView: View {
    let competition: Competition
    @State private var tab = Tab.table
    @State private var season: String?
    @State private var seasons: [String] = []

    enum Tab: Hashable { case table, matches, bracket }

    var body: some View {
        ScrollView {
            VStack(alignment: .leading, spacing: 16) {
                SegmentedPicker(options: tabs, selection: $tab)
                switch tab {
                case .table:
                    Loader(id: season) { try await APIClient.shared.standings(competition.slug, season: season) } content: { groups in
                        if groups.isEmpty {
                            EmptyState(text: "Таблицы нет")
                        } else {
                            ForEach(groups, id: \.group) { StandingsCard(group: $0) }
                        }
                    }
                case .matches:
                    Loader(id: season, live: { $0.contains { $0.status == .live } }) {
                        try await APIClient.shared.matches(competition.slug, season: season)
                    } content: { matches in
                        LazyVStack(alignment: .leading, spacing: 16) {
                            // shortcut: a long season renders from round 1; scroll to the current round if it gets annoying
                            ForEach(matches.grouped(by: \.round)) { group in
                                CardSection(title: roundTitle(group.key)) {
                                    Rows(items: group.items) { match in
                                        NavigationLink(value: Route.match(match.id)) { MatchRow(match: match, showDate: true) }
                                            .buttonStyle(.plain)
                                    }
                                }
                            }
                        }
                    }
                case .bracket:
                    Loader(id: season) { try await APIClient.shared.bracket(competition.slug, season: season) } content: { bracket in
                        if let bracket { BracketView(bracket: bracket) } else { EmptyState(text: "Сетки пока нет") }
                    }
                }
            }
            .padding(16)
        }
        .screen()
        .navigationTitle(competition.name)
        .navigationBarTitleDisplayMode(.inline)
        .toolbar {
            if !seasons.isEmpty {
                Menu {
                    Picker("Сезон", selection: $season) {
                        ForEach(seasons, id: \.self) { Text($0).tag(Optional($0)) }
                    }
                } label: {
                    Text(season ?? competition.currentSeason ?? "Сезон").font(.subheadline.weight(.semibold))
                }
                .accessibilityLabel("Сезон")
            }
        }
        .task { seasons = (try? await APIClient.shared.seasons(competition.slug)) ?? [] }
    }

    private var tabs: [(value: Tab, title: String)] {
        competition.kind == "league"
            ? [(.table, "Таблица"), (.matches, "Матчи")]
            : [(.table, "Таблица"), (.matches, "Матчи"), (.bracket, "Сетка")]
    }

import SwiftUI

/// Rounds as columns; pairs spread evenly so each sits opposite its two feeders. No connector lines in the skeleton.
struct BracketView: View {
    let bracket: Bracket
    private let cardHeight: CGFloat = 76

    var body: some View {
        let tallest = CGFloat(bracket.rounds.map(\.matchups.count).max() ?? 1) * (cardHeight + 12)
        ScrollView(.horizontal, showsIndicators: false) {
            HStack(alignment: .top, spacing: 16) {
                ForEach(bracket.rounds, id: \.stage) { round in
                    column(roundTitle(round.stage)) {
                        VStack(spacing: 0) {
                            ForEach(round.matchups.indices, id: \.self) { index in
                                Spacer(minLength: 6)
                                MatchupCard(matchup: round.matchups[index]).frame(height: cardHeight)
                                Spacer(minLength: 6)
                            }
                        }
                        .frame(height: tallest)
                    }
                }
                if let third = bracket.thirdPlace {
                    column(roundTitle("bronze")) { MatchupCard(matchup: third).frame(height: cardHeight) }
                }
            }
            .padding(.vertical, 4)
        }
    }

    private func column<Content: View>(_ title: String, @ViewBuilder content: () -> Content) -> some View {
        VStack(alignment: .leading, spacing: 8) {
            Text(title).font(.sectionTitle).foregroundStyle(Color.textSecondary).accessibilityAddTraits(.isHeader)
            content()
        }
        .frame(width: 220)
    }
}

private struct MatchupCard: View {
    let matchup: Matchup

    var body: some View {
        let card = VStack(spacing: 8) {
            line(matchup.home, score: matchup.homeScore)
            line(matchup.away, score: matchup.awayScore)
        }
        .padding(.horizontal, 12)
        .frame(maxHeight: .infinity)
        .glassCard(radius: 12)
        if let id = matchup.matchIds.last {
            NavigationLink(value: Route.match(id)) { card }.buttonStyle(.plain)
        } else {
            card
        }
    }

    private func line(_ team: TeamRef?, score: Int?) -> some View {
        let lost = team != nil && matchup.winnerId != nil && team?.id != matchup.winnerId
        let color = lost ? Color.textSecondary : Color.textPrimary
        return HStack(spacing: 8) {
            if let team {
                Logo(url: team.logoUrl, size: 20, label: team.name)
                Text(team.name).font(.subheadline.weight(lost ? .regular : .semibold)).foregroundStyle(color).lineLimit(1)
            } else {
                Text("—").font(.subheadline).foregroundStyle(Color.textTertiary).accessibilityLabel("Ещё не определён")
            }
            Spacer(minLength: 4)
            if let score {
                Text("\(score)").font(.digits(17, relativeTo: .body)).monospacedDigit().foregroundStyle(color)
            }
        }
    }
}
