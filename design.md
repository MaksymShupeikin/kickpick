# KickPick — дизайн-система

Источник: гайд `ui-ux-pro-max` (`.claude/skills/ui-ux-pro-max`). Запрос: `sports live scores football mobile app minimal monochrome glassmorphism dark gray`, плюс поиск по доменам `style`, `color`, `ux` и стеку `swiftui`.
Этот файл — единственный источник правил по внешнему виду iOS-приложения. Если экран расходится с ним, исправляется экран.

## 1. Что взято из гайда и что изменено

| Гайд предложил | Решение | Почему |
|---|---|---|
| Стиль **Glassmorphism**: blur 10–20, полупрозрачный белый 10–30 %, рамка 1 px белым 20 %, блик, глубина | **Берём** | совпадает с запросом «frosted glass» |
| Яркий цветной фон под стеклом | **Заменяем** на серый фон с мягкими белыми световыми пятнами | стеклу нужно, что размывать, но цвет запрещён |
| Акцент CTA `#2563EB` (синий) | **Отвергаем**, акцент — белый `#FFFFFF` | требование: белый акцент, никакого сине-фиолетового |
| Шрифты Barlow Condensed / Barlow («Sports, athletic, condensed») | **Barlow Condensed — только для цифр**, весь текст — SF Pro (заголовки — `.condensed`) | в Barlow нет кириллицы (проверено по таблице символов); SF Pro поддерживает Dynamic Type |
| Объём кнопок (Tactile UI: нажатие с уменьшением масштаба, пружина, тактильный отклик; Soft UI: мягкие тени 200–300 мс) | **Берём** объём светом и тенью | требование «3D-эффект у кнопок» |
| Skeuomorphism (текстуры, градиенты на 8–12 точек) | **Отвергаем** | в гайде помечено «Performance: Poor», против «максимально просто» |
| Паттерн App Store Landing | **Не применяем** | это для лендинга, у нас приложение |
| Иконки SVG (Heroicons/Lucide) | **SF Symbols** | нативный аналог на iOS, один набор |

## 2. Принципы

1. Максимально просто: серый фон, стеклянные карточки, белый текст и белый акцент. Больше ничего.
2. Белый — единственный акцентный цвет. Других цветов нет, кроме функциональных пометок из §3.3.
3. Объём есть только у кнопок и выбранных сегментов. Карточки плоские, это стекло.
4. В интерфейсе только реальные изображения: настоящие гербы, логотипы турниров и фото игроков. Нарисованных заглушек нет.
5. Одна тема — тёмно-серая (`.preferredColorScheme(.dark)`). Белый акцент на светлом фоне не читается, поэтому светлой темы нет.

## 3. Цвета

### 3.1 Фон
- Базовый вертикальный градиент: `#2B2B2F` сверху → `#1A1A1D` снизу (только оттенки серого).
- Два световых пятна под стеклом: белые радиальные градиенты с непрозрачностью 7 % (радиус ≈ 60 % ширины экрана). Одно — сверху слева, другое — по центру справа. Пятна неподвижны.
- Компонент: `AppBackground`, кладётся под каждый экран (`.background { AppBackground() }`).

### 3.2 Токены (`Color+Tokens.swift`)

| Токен | Значение | Где |
|---|---|---|
| `textPrimary` | `#FFFFFF` | названия, счёт, заголовки |
| `textSecondary` | белый 64 % | время, проигравшая команда, подписи |
| `textTertiary` | белый 52 % | заголовки колонок таблицы, пустые состояния |
| `accent` | `#FFFFFF` | основная кнопка, выбранный сегмент, выделение |
| `onAccent` | `#111113` | текст и иконки на белом |
| `hairline` | белый 10 % | разделители строк (имя `separator` занято в SwiftUI) |
| `glassStroke` | градиент: белый 22 % сверху → белый 5 % снизу | рамка стекла (блик сверху) |
| `glassTint` | белый 6 % | заливка поверх материала |
| `solidSurface` | `#2C2C30` | замена стекла при включённом «Понижении прозрачности» |

Проверка контраста (на самом тёмном участке под стеклом ≈ `#2A2A2E`): `textSecondary` ≈ 6,8:1, `textTertiary` ≈ 5,0:1 — оба выше 4,5:1. Белый текст на белом 64 % и ниже запрещён.

### 3.3 Функциональные цвета (только маленькие пометки, никогда не фон и не текст)
- Жёлтая карточка — прямоугольник 8×11 pt цвета `#FFD60A`.
- Красная карточка — прямоугольник 8×11 pt цвета `#FF453A`.
- Матч идёт — точка 6 pt цвета `#FF453A` рядом с минутой. Цвет никогда не единственный признак: рядом всегда есть текст минуты, например `67'`.

### 3.4 Запрещено
- Сине-фиолетовые градиенты, а также любые цветные градиенты и цветные фоны.
- Неоновое свечение, цветные тени.
- Цвета зон таблицы (Лига чемпионов, вылет и т.п.).

## 4. Типографика

| Роль | Шрифт | Размер / вес | Dynamic Type |
|---|---|---|---|
| Заголовок экрана | SF Pro, `.fontWidth(.condensed)` | 34 / Bold | `.largeTitle` |
| Заголовок секции | SF Pro, `.condensed` | 20 / Semibold | `.title3` |
| Основной текст, названия команд | SF Pro | 17 / Regular (победитель — Semibold) | `.body` |
| Вторичный текст | SF Pro | 15 / Regular | `.subheadline` |
| Мелкий текст (минимум) | SF Pro | 13 / Medium | `.footnote` |
| Счёт в шапке матча | Barlow Condensed | 48 / Bold | `relativeTo: .largeTitle` |
| Счёт в строке матча, минута | Barlow Condensed | 22 / Bold | `relativeTo: .title3` |
| Цифры в таблицах, номера игроков | Barlow Condensed | 17 / SemiBold | `relativeTo: .body` |

- Barlow Condensed (OFL) вшивается двумя файлами: `BarlowCondensed-SemiBold.ttf` и `BarlowCondensed-Bold.ttf`. Регистрируются через `UIAppFonts`.
- У всех цифр, которые обновляются в лайве, включается `.monospacedDigit()`, чтобы строка не дёргалась.
- Текст мельче 13 pt не используется.

## 5. Сетка и форма

- Отступы: шкала 4 / 8 / 12 / 16 / 24 / 32. Край экрана — 16, внутренний отступ карточки — 16, между карточками — 12.
- Скругления: строки и мелкие плашки — 12, карточки — 20, кнопки и сегменты — капсула.
- Касание: минимум 44×44 pt, между соседними целями — 8 pt.

## 6. Материалы

### 6.1 Стекло (`.glassCard()`)
```swift
.background(.ultraThinMaterial, in: .rect(cornerRadius: 20))
.overlay(RoundedRectangle(cornerRadius: 20).fill(Color.glassTint))
.overlay(RoundedRectangle(cornerRadius: 20).strokeBorder(Color.glassStroke, lineWidth: 1))
.shadow(color: .black.opacity(0.25), radius: 24, y: 8)
```
- При `accessibilityReduceTransparency`: заливка `solidSurface` без материала, рамка остаётся.
- Стекло на стекле не кладётся. Внутри карточки строки разделяются линией `hairline`.

### 6.2 Кнопки с объёмом
Объём создаётся светом сверху и тенью снизу. Текстур нет, градиенты только серо-белые.

**Основная (белая)** — `PrimaryButtonStyle`:
- Заливка: линейный градиент `#FFFFFF` → `#E4E4E7` сверху вниз.
- Внутренний блик: обводка 1 pt по верхней половине, белая 100 % → 0 %.
- Нижняя кромка: внутренняя обводка 1 pt `#000000` 12 % по нижнему краю.
- Внешняя тень в два слоя: `black 30 %, r 1, y 1` и `black 35 %, r 16, y 8`.
- Текст `onAccent`, SF Pro 17 Semibold. Высота 50, форма — капсула.
- Нажатие: `scale 0.97`, тени `r 4, y 2`, градиент темнее на 4 %; `.spring(response: 0.25, dampingFraction: 0.7)`; `.sensoryFeedback(.impact(weight: .light), trigger:)`.

**Вторичная (стеклянная)** — `GlassButtonStyle`: стекло из §6.1 в форме капсулы + тот же блик и та же двухслойная тень, текст `textPrimary`. Нажатие — то же.

**Выбранный сегмент** (Таблица / Матчи / Сетка, вчера / сегодня / завтра): дорожка — стеклянная капсула, выбранный сегмент — белая объёмная капсула с текстом `onAccent`. Переезжает за 200 мс через `matchedGeometryEffect`.

При `accessibilityReduceMotion` нажатие меняет только тень, без масштаба. Переезд сегмента — без анимации.

### 6.3 Таббар и навигация
- Системные `TabView` и `NavigationStack` (на iOS 26 таббар стеклянный автоматически). На iOS 17–18: `.toolbarBackground(.ultraThinMaterial, for: .tabBar)`.
- Табы: «Матчи» (`sportscourt`), «Турниры» (`trophy`), «Поиск» (`magnifyingglass`).

## 7. Изображения — только реальные

| Что | URL (CDN FotMob, проверено) | Размер в UI |
|---|---|---|
| Герб клуба или сборной | `images.fotmob.com/image_resources/logo/teamlogo/{teamId}.png` | 24 в строке, 64 в шапке матча, 72 на экране команды |
| Логотип турнира | `images.fotmob.com/image_resources/logo/leaguelogo/dark/{leagueId}.png` — монохромно-белый вариант для тёмного фона | 20 в заголовках групп, 40 в списке турниров |
| Фото игрока | `images.fotmob.com/image_resources/playerimages/{playerId}.png` | 36 в составе, 96 в карточке |

- URL отдаёт наш API (`logo_url`, `photo_url`). Приложение URL не собирает.
- Пока картинка грузится, на её месте стеклянный круг того же размера, поэтому вёрстка не прыгает.
- Если загрузить не удалось, остаётся тот же пустой круг. Инициалов, сгенерированных гербов и эмодзи нет.
- Кеш: `URLCache` на 50 МБ в памяти и 200 МБ на диске.
- У логотипа `accessibilityLabel` — название команды или турнира.

## 8. Компоненты

### Строка матча (`MatchRow`)
```
┌───────────────────────────────────────────┐
│ 18:45      [герб] Barcelona            2  │
│            [герб] Real Madrid          1  │
└───────────────────────────────────────────┘
```
- Левая колонка (ширина 52): время начала, минута `67'` с красной точкой, `Конец`, `Отменён` или дата. Это обычный текст `textSecondary`. В лайве минута — `textPrimary`.
- Победитель — `textPrimary` Semibold, проигравший — `textSecondary`. Ничья: оба `textPrimary` Regular.
- Справа — счёт, Barlow Condensed 22. До начала матча пусто.
- **Никаких чипов, бейджей, тегов и плашек** рядом с текстом: ни «LIVE», ни «FT», ни формы команды, ни стадии.
- Вся строка — одна цель касания и один элемент доступности: «Барселона 2, Реал Мадрид 1, завершён».

### Группа матчей турнира
Заголовок вне карточки: логотип турнира 20 + название, SF Pro 15 Semibold `textSecondary`. Ниже — одна стеклянная карточка, строки внутри разделены линией `hairline`.

### Таблица
- Стеклянная карточка, высота строки 44.
- Колонки: `#` (Barlow) · герб 24 + название · `И` · `Р` · `О`. Очки — Barlow Bold `textPrimary`, остальные цифры — `textSecondary`.
- Заголовки колонок — 13 Medium `textTertiary`.
- В групповых турнирах на каждую группу своя карточка с заголовком «Группа A».

### Сетка плей-офф
- Горизонтальный скролл по раундам, каждый раунд — колонка с заголовком «1/8», «1/4», «1/2», «Финал».
- Пара — маленькая стеклянная карточка в две строки: герб 20, название, сумма счёта. Победитель `textPrimary`, проигравший `textSecondary`.
- Пары в колонке распределены по высоте так, чтобы стоять напротив своих пар из прошлого раунда. Соединительных линий в каркасе нет.
- У лиг сегмента «Сетка» нет. У кубков и турниров сборных он есть всегда; если сетки ещё нет — пустое состояние «Сетки пока нет».
- Неизвестный пока соперник — текст «—» `textTertiary`.

### Шапка матча
Стеклянная карточка: два герба по 64 с названиями под ними, между ними счёт (Barlow 48) и статус текстом под счётом. В лайве данные обновляются раз в 30 с без анимации цифр.

### События матча
- Список в стеклянной карточке: минута (Barlow, колонка 40) · иконка · имя игрока, под ним мелко ассист или кто ушёл.
- События хозяев выровнены влево, гостей — вправо.
- Иконки (SF Symbols, белые): гол — `soccerball`, замена — `arrow.left.arrow.right`. Карточка — прямоугольник из §3.3.

### Статистика матча
Строка: значение хозяев · название · значение гостей. Под ней тонкая полоса 4 pt: доля хозяев белая, гостей — белая 30 %.

### Команда и игрок
- **Команда**: шапка (герб 72, название), состав по позициям — строки с фото 36, именем и номером (Barlow) справа. Ниже секции «Последние матчи» и «Ближайшие».
- **Игрок**: фото 96, имя, герб клуба 24 и название клуба. Факты — пары «подпись / значение» в стеклянной карточке: номер, позиция, возраст, страна. Статистика сезона: голы, ассисты, карточки, рейтинг.

### Поиск
- Системный `.searchable`, запрос уходит через 300 мс после последнего ввода.
- Результаты — секции «Турниры», «Команды», «Игроки», каждая в стеклянной карточке: логотип или фото + название + вторичная строка (страна или клуб).

### Загрузка, пусто, ошибка
- Загрузка: лента матчей — её же разметка с `.redacted(reason: .placeholder)`; остальные экраны — системный `ProgressView` по центру. Пустого экрана во время загрузки нет.
- Пусто: одна строка `textTertiary` по центру карточки, например «Матчей нет».
- Ошибка: короткий текст и вторичная кнопка «Повторить».

## 9. Движение

- Длительности 150–300 мс. Пружина только у кнопок.
- Анимируется не больше 1–2 элементов на экране.
- Бесконечная анимация допустима только у системного индикатора загрузки. Точка лайва не пульсирует.
- `accessibilityReduceMotion` проверяется везде, где есть масштаб или перемещение.

## 10. Запрещено (сводно)

- Сине-фиолетовые и любые цветные градиенты, цветные фоны и неон.
- Эмодзи в любом месте интерфейса.
- Чипы, бейджи, теги и плашки рядом с текстом в карточках.
- Выдуманные или сгенерированные гербы, инициалы вместо герба, картинки-заглушки.
- Текстуры, шум, «кожа», «металл».
- Стекло на стекле. Текст с контрастом ниже 4,5:1.

## 11. Проверка перед сдачей экрана

- [ ] Есть только серый, белый, функциональные пометки из §3.3 и сами логотипы; цветных градиентов нет.
- [ ] Нет эмодзи и чипов; статус — обычный текст.
- [ ] Все гербы, логотипы и фото взяты из URL API; при ошибке загрузки остаётся пустой круг.
- [ ] Цели касания ≥ 44 pt, отступ между ними ≥ 8 pt.
- [ ] Dynamic Type до XXL: ничего не обрезается, строки переносятся.
- [ ] Включено «Понижение прозрачности»: стекло стало сплошным, текст читается.
- [ ] Включено «Уменьшение движения»: нет масштабов и переездов.
- [ ] У логотипов и строк матчей есть `accessibilityLabel`.
- [ ] Цифры лайва моноширинные и не дёргают строку.
